# 🤖 AI Study Manager

AI-powered Study Management Platform built with MERN Stack.

## Features

- User Authentication (JWT)
- Notes Management
- Categories & Pin Notes
- AI Summarizer (Groq API)
- AI Quiz Generator
- Quiz History Tracking
- Study Planner
- MongoDB Atlas Integration
- Responsive UI with Tailwind CSS

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### AI
- Groq API
- Llama 3.3 70B

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
